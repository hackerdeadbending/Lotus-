# Lotus

**Тихо. Безопасно. Красиво.**

Lotus — Android-приложение на Kotlin и Jetpack Compose. Сейчас репозиторий содержит ранний UI-прототип: экран приветствия, демонстрационный список чатов и дизайн-тему.

## Текущий статус

- Android UI-прототип; поддержка Android 8.0+ (API 26+).
- APK собирается через GitHub Actions для проверки интерфейса.
- **Реальная доставка сообщений, аккаунты, сквозное шифрование, Signal Protocol, постквантовая криптография, Tor и mesh-сеть пока не реализованы.** Не используй текущую сборку для приватной переписки и не считай её защищённым мессенджером.

## Скачать тестовую сборку

1. Открой [Releases](https://github.com/hackerdeadbending/Lotus-/releases).
2. Скачай `app-debug.apk` из последнего prerelease.
3. Установи на Android.

Если Android сообщает о конфликте подписи с ранее установленной сборкой, удали старую тестовую версию Lotus и установи APK заново. Удаление приложения удалит его локальные данные.

## Сборка

Требуются JDK 17 и Android SDK. В корне проекта:

```sh
./gradlew assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.
