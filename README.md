# Lotus

**Anonymous. Resilient. Beautiful.**

Lotus — максимально анонимный и защищённый мессенджер для сложных условий.

### Ключевые возможности
- Полная анонимность (нет телефона, email, постоянных ID)
- End-to-end шифрование (Signal Protocol + Post-Quantum)
- Устойчивость к плохому интернету и блокировкам (Tor + mesh)
- Безопасное невосстанавливаемое удаление сообщений
- Невидимость активности
- Встроенный защищённый браузер
- Красивый, удобный и приятно анимированный интерфейс

### Дизайн
Современный Material 3 + Jetpack Compose  
Мягкая цветовая палитра вдохновлённая лотосом  
Плавные анимации, микро-взаимодействия, приятная типографика

### Статус
Проект в активной разработке. Сейчас создаётся фундамент: дизайн-система, структура приложения и базовый UI.

### Как собрать
1. Клонируй репозиторий
2. Открой в Android Studio (Giraffe или новее)
3. Sync Gradle
4. Run на эмуляторе / устройстве

```bash
git clone https://github.com/hackerdeadbending/Lotus-.git
cd Lotus-
```
